# Day 2 — Seven-Element Mana Chart

**Date:** 2026-10-22

## What I worked on

Built [Seven-Element Mana Chart](https://github.com/LadyHannelore/Seven-Element-Mana-Chart),
a dependency-free web app for visualizing relative affinity for Water, Fire,
Wind, Earth, Life, Light, and Darkness. Each element can be adjusted with a
slider or number field, and the values are displayed in an SVG radar chart.

## What I learned

I practiced turning a set of numeric inputs into a visual summary, and learned
how SVG can render a chart directly in the browser without a library or build
step.

## Challenges

The chart needed to reflect each input clearly while keeping the seven-element
comparison easy to read. I also included a reset control so the values can
quickly return to their default midpoint.
