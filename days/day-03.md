# Day 3 — The Academy Library Dash

**Date:** 2026-10-23

## What I worked on

Built [The Academy Library Dash](https://github.com/LadyHannelore/Tea-Party-Timing-Game),
a self-contained browser game about helping an overworked library keeper before
heading to tea. Each playthrough presents six randomly selected mishaps, and I
choose how to handle them while trying to reach the reading room by the five
o'clock bell.

## What I learned

I practiced building a short game loop around randomized events, player choices,
and a clear deadline. The warning lamps also give the player a visual cue about
how the journey is going.

## Challenges

The central challenge was making each decision feel like part of a race against
the clock. The random event selection and warning lamps help make each attempt
feel varied while keeping the goal easy to understand.
