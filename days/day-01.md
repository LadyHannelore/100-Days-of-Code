# Day 1 — Movable Type Page

**Date:** 2026-10-21

## What I worked on

Built [Movable Type Page](https://github.com/LadyHannelore/Movable-Type-Page), a
standalone browser project that turns entered text into a parchment-style printed
page. The page includes an aged background and woven-style border, randomized
per-character ink variation, and typesetting and press animations. Text updates
live, with controls to replay printing and adjust the ink variation.

## What I learned

This project was a practical exercise in combining CSS styling and animation
with JavaScript-driven text rendering to create a more tactile browser
experience. Small variations in each character's ink and placement help make
the output feel less uniform.

## Challenges

The main design challenge was making the randomized ink effect feel intentional
while keeping the text readable and the printing animation clear.
